# www.naturailes.org

Daniel Quèze's nature photos. The site used to run on a home-made PHP/MySQL
engine; it is now built with [Eleventy](https://www.11ty.dev/) and published
with GitHub Pages. URLs, texts, feeds (including their GUIDs) and look are
those of the old site. Photos are plain responsive images (up to 1600×1200,
signed "Daniel Quèze"); comments are read-only.

## Layout

- `posts/<id>-<slug>.md`: one file per photo. The front matter has the photo's
  `id`, `title`, `slug` (for the URLs), `date` (Paris time), `category` (an id
  from `_data/categories.json`), `author`, the original's `width` and `height`,
  and its `comments`. The body is the photo's description, in HTML.
- `photos/`: the published images, generated by `npm run photos` and committed.
- `_data/oldImageUrls.json`: image URLs of the old site still used by other
  sites and search engines (`p<id>-<slug>-<w>x<h>.jpg` resized photos, old
  thumbnail URLs), with their photo id. The build copies the published image
  of the closest size there. Made by `import/old-image-urls.mjs` from the old
  server's logs.
- `_data/site.js`: settings. `lib/site.js`: URLs, pages, feeds and redirects,
  computed like the old engine did. `*.njk`, `_includes/`: templates.
- `originals/`: the private
  [naturailes-private](https://github.com/fqueze/naturailes-private) repository
  (original photos, old PHP site, database dump), as a git submodule. Only
  needed to generate images.
- `tools/photos/`: the image script, with its own dependencies.
- `tools/compare.mjs`: compares the site with the old one.
- `import/`: export of the old database and conversion to `posts/` (not used
  by the build).

## Getting it

    git clone --recurse-submodules git@github.com:fqueze/naturailes.org.git

or, in an existing clone, `git submodule update --init`. The submodule is
private and large; it isn't needed to build the site.

## Building

    npm install
    npm run build        # writes _site/
    npm run serve        # local server, rebuilding on changes

Pushing to `main` runs `.github/workflows/eleventy_build.yml`, which builds
the site and publishes `_site/` to the `gh-pages` branch (in the repository's
Settings > Pages, the source must be the `gh-pages` branch; the custom domain
www.naturailes.org comes from `CNAME`). The deployment doesn't fetch the
submodule and does no image processing: it generates the HTML and feeds and
copies `photos/`.

## Adding a photo

1. Add the original as `<id>.jpg` in the private repository (`originals/`),
   with a new id (the largest existing one + 1); commit and push it there.
2. Create `posts/<id>-<slug>.md`, e.g.:

       ---
       id: 787
       title: "mésange bleue"
       slug: "mesange-bleue"
       date: 2027-03-01T10:00:00
       category: 5
       author: daniel
       width: 5616
       height: 3744
       ---
       <p>Optional description.</p>

   `width` and `height` are those of the original (the script checks them).
3. Generate its images (once: `npm install --prefix tools/photos`):

       npm run photos

   It only processes the photos whose images are missing in `photos/`, so
   delete them to regenerate them. `npm run photos -- 787` processes only
   that photo.
4. Commit `posts/`, `photos/` and the submodule update (`originals`), and push.

Photos dated after the last photo of the old site get https links in the
feeds; the old ones keep their http links, so that feed readers don't show
them again.

## Published images

For each photo, `photos/<id>-<width>.jpg` at widths 400, 800, 1200 and the
largest that fits in 1600×1200 (never upscaled), JPEG quality 80, and the
thumbnail `photos/<id>-mini.jpg` (the old site's one when `originals/mini/`
has it). The signature is drawn with the Corinthia font
(`tools/photos/fonts/`, SIL Open Font License), imitating the one on Daniel's
prints.

Their metadata only has:
- EXIF Artist "Daniel Quèze" and Copyright "© Daniel Quèze", and XMP
  dc:creator, dc:rights, photoshop:Credit and xmpRights:Marked;
- the shooting information of the original: Make, Model, LensModel (from the
  Canon maker notes when needed), ExposureTime, FNumber, ISO, FocalLength,
  FocalLengthIn35mmFormat, ExposureProgram, ExposureBiasValue, ExposureMode,
  MeteringMode, Flash, WhiteBalance and DateTimeOriginal.

Everything else (GPS, serial numbers, owner name, maker notes, embedded
thumbnails, editing software) is left out.

## Comments

They are in the front matter of the posts. To remove one, delete it there
(or, while `import/` exists, add its id to `import/excluded-comments.json`
and run `node import/convert.mjs`; `node import/review-comments.mjs` makes a
page listing them all).

## Checking against the old site

With the old site running locally, after `npm run build`:

    node tools/compare.mjs http://localhost:8105/ [--refresh] [--verbose]

It crawls the old site (cached in `.cache/`), checks that every URL that
answered 200 there exists in `_site/` (directly or as a redirect page), and
compares the visible text of pages and feeds.
